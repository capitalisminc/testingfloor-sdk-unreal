# Agent Guidelines

This repository is public. Anyone can read everything you write here: code, tests, docs, examples, commit messages, branch names, pull request titles and descriptions, review replies, issues and comments.

Keep private information out of all of it:

- No customer, studio or game names, and no build versions, build or record IDs, sizes or timings from real builds.
- No links to private repositories, CI runs, dashboards, logs or app pages. No internal hostnames, service names or environment variables.
- No production data: log excerpts, errors with real identifiers, email addresses, keys or tokens.

When a change comes from something that happened in production, describe the behavior in general terms, for example "an upload failed when one status check lost its connection". Keep the specifics in private channels. In examples and tests, use placeholders such as `example-studio`, `my-game` and `1.2.3`.

If you find private information that's already published, don't rewrite history. Tell a maintainer.
